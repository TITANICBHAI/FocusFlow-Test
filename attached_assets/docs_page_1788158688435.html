¿Qué es?

What is a .focusflow file?什么是 .focusflow 文件？Was ist eine .focusflow-Datei?Qu'est-ce qu'un fichier .focusflow ?.focusflow ファイルとは？.focusflow 파일이란?¿Qué es un archivo .focusflow?

A .focusflow file is a plain UTF-8 JSON document with a .focusflow extension. It is FocusFlow's native backup and schedule exchange format — the app can export its entire state (all tasks, settings, blocking config, and user profile) into one file and reimport it on any device running FocusFlow.

.focusflow 文件是一个具有 .focusflow 扩展名的纯 UTF-8 JSON 文档。它是 FocusFlow 的原生备份和日程交换格式——该应用可以将其全部状态（所有任务、设置、屏蔽配置和用户资料）导出到一个文件中，并在任何运行 FocusFlow 的设备上重新导入。

Eine .focusflow-Datei ist ein einfaches UTF-8-JSON-Dokument mit der Erweiterung .focusflow. Es ist das native Backup- und Zeitplanformat von FocusFlow — die App kann ihren gesamten Zustand in eine Datei exportieren und auf jedem Gerät mit FocusFlow reimportieren.

Un fichier .focusflow est un document JSON UTF-8 brut avec l'extension .focusflow. C'est le format natif de sauvegarde et d'échange de plannings de FocusFlow — l'application peut exporter l'intégralité de son état dans un seul fichier et le réimporter sur n'importe quel appareil FocusFlow.

.focusflowファイルは、.focusflow拡張子を持つプレーンなUTF-8 JSONドキュメントです。FocusFlowのネイティブなバックアップおよびスケジュール交換形式で、アプリはすべての状態を1つのファイルにエクスポートし、任意のデバイスにインポートできます。

.focusflow 파일은 .focusflow 확장자를 가진 일반 UTF-8 JSON 문서입니다. FocusFlow의 기본 백업 및 일정 교환 형식으로, 앱은 전체 상태를 하나의 파일로 내보내고 모든 기기에서 다시 가져올 수 있습니다.

Un archivo .focusflow es un documento JSON UTF-8 plano con extensión .focusflow. Es el formato nativo de copia de seguridad e intercambio de horarios de FocusFlow — la aplicación puede exportar su estado completo a un archivo e importarlo en cualquier dispositivo.

from datetime import datetime, timedelta

IST = timedelta(hours=5, minutes=30)

def ist_to_utc(date_str, hour, minute):
    dt = datetime(int(date_str[:4]), int(date_str[5:7]), int(date_str[8:]), hour, minute)
    return (dt - IST).strftime("%Y-%m-%dT%H:%M:%S.000Z")
