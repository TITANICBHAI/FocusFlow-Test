Highest-impact UI improvements
1. Add a compact step indicator
At the top:

1  Core access        2  Iron Mode

For Standard Mode, it could simply show:

Core access

For Iron Mode:

Core access  ✓     Iron Mode setup

This makes the two-mode structure immediately understandable.

2. Keep the main CTA visible
Currently, users must scroll through the permission cards before reaching the continuation button.

A better approach:

Keep the button in a sticky bottom area.
Change the button label based on state:
Continue with Standard
Continue Iron Mode setup
Enter FocusFlow
Activate Iron Mode
Add a small line above it:
3 of 4 essential permissions ready
4 of 5 Iron Mode layers active
This would probably be the biggest usability improvement.

3. Make the permission card action easier to discover
Currently, the user taps a card to expand it, then taps the grant button.

That is two taps before the actual Android settings action.

A cleaner card could have:

Accessibility Service
Detects blocked apps instantly
[Set up]                 [Why?]

Set up opens Android settings directly.
Why? expands the explanation.
Granted cards show:
Ready
a green checkmark
optional Review action
This makes the onboarding more task-oriented without making it more complicated.

Standard Mode improvements
Standard Mode should feel like the quick, safe path.

I would add:

A small Recommended for most users label.
A clear estimate such as:
4 essential access steps
A calmer subtitle:
Get app blocking working first. You can strengthen protection later.
Hide the Iron Mode promotion until after the main Standard CTA, so it does not compete with the required setup.
Standard Mode target feeling
I can get started without understanding every advanced feature.

Current rating after these changes could reach approximately 9/10.

Iron Mode improvements
Iron Mode should feel intentional, but not intimidating.

I would add:

A simple protection summary
At the top of the Iron Mode step:

Iron Mode adds 3 extra resistance layers
Network restriction
Force-stop resistance
Defense Password

Then keep the detailed cards below.

Separate required from optional
Use clearer labels:

CORE PROTECTION
Required for app blocking
IRON MODE LAYERS
Optional resistance against bypassing

This prevents users from thinking every Android permission is mandatory.

Better completion state
When the actual selected Iron Mode setup is ready:

Iron Mode activated
Your focus protections are ready.

Use:

Indigo activation panel
Green completion checks
Orange only on the Iron Mode identity badge
Avoid confetti or a large celebration; the current restrained direction is better for FocusFlow.

Current Iron Mode rating: approximately 8.3/10. With a clearer required/optional distinction and a sticky CTA, it could reach 8.8–9/10.

Small polish worth adding
Haptic feedback when selecting Standard or Iron Mode.
A clear Checking access… state after returning from Android Settings.
“Last checked just now” only if it does not add clutter.
Ensure the bottom CTA respects Android safe-area spacing.
Improve contrast for small orange explanatory text in dark mode.
Add test IDs to mode selectors, permission cards, and main buttons.
What I would avoid
Adding another welcome screen.
Adding more permission cards.
Making the whole screen orange.
Adding confetti or long celebrations.
Adding Reanimated or another animation library.
Putting every explanation directly on the first screen.
My priority order
Sticky contextual CTA
Clear Core → Iron Mode step indicator
Direct Set up action on permission cards
Stronger Standard/Iron comparison
Android return/checking feedback
Haptics and small accessibility polish
The main design principle should be:

Make the next action obvious, while keeping the reason understandable.
