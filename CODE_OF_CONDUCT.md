# Code of Conduct

## Our commitment

We want FocusFlow to be a welcoming, respectful, and constructive project for
everyone. Participation in this project is governed by this Code of Conduct.

## Expected behavior

Examples of behavior that contribute to a positive environment include:

- Being respectful and considerate of different viewpoints and experiences.
- Giving and receiving constructive feedback.
- Focusing on what is best for the project and its users.
- Taking responsibility for mistakes and learning from them.
- Respecting the privacy and security of other contributors and users.

## Unacceptable behavior

Examples of unacceptable behavior include:

- Harassment, discrimination, personal attacks, or deliberately insulting
  comments.
- Trolling, sustained disruption, or bad-faith participation.
- Publishing someone else’s private information without permission.
- Introducing malicious code, security vulnerabilities, or deceptive changes.
- Any conduct that would be inappropriate in a professional community.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, and
pull requests that violate this Code of Conduct. They may also temporarily or
permanently restrict participation when necessary.

To report a conduct concern, contact the repository maintainers privately
through GitHub. Please do not create a public issue for sensitive reports.
